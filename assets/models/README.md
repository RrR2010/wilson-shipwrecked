# Runtime 3D Models

Place runtime-ready `.glb` assets here. This directory is intentionally visible to Godot and should contain only files that are valid project resources.

Prefer semantic subfolders such as `characters/`, `environment/`, `props/`, and `structures/` as those categories become populated.

Editable `.blend` sources belong in `../source/`; generators in `../generators/`; previews and intermediates remain outside the Godot import surface.
