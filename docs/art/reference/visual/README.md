# Visual Reference Sheets

This directory stores the approved visual reference sheets accompanying the textual specifications in `docs/art/reference/`.

## Naming contract

Each visual sheet uses the same numeric prefix and stem as its textual reference:

```text
../REFERENCE_01_SHAPE_GRAMMAR.md
REFERENCE_01_SHAPE_GRAMMAR.png
```

## Authority rule

The PNGs are **visual evidence/examples**, not standalone specifications.

Use them together with the corresponding textual reference. If an AI-generated image contains an accidental artifact, impossible join, inconsistent count, decorative detail or other ambiguity, the textual art contracts and cross-cutting asset catalog win.

Do not infer new gameplay capabilities, states, anchors or object taxonomy from details that appear only in a generated sheet.

A sheet may be regenerated later when the project deliberately changes its visual grammar; preserve the canonical filename so consumers do not need new routing logic.
