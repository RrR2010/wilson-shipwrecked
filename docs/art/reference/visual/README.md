# Visual Reference Sheets

This directory stores approved/generated visual reference sheets that accompany the textual specifications in `docs/art/reference/`.

## Naming

Use the same numeric prefix as the corresponding textual reference.

Example:

```text
REFERENCE_01_SHAPE_GRAMMAR.md
visual/REFERENCE_01_SHAPE_GRAMMAR.png
```

## Current generated sheet
