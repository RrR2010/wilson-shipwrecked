# Asset Catalog — Entity Families

This is the operational content/model backlog for physical entity, resource, component, container, tool, salvage and comfort families. See [`README.md`](README.md) for token grammar, authority, `Spec`, production status and priority rules.

A row identifies a reusable semantic/content family, **not necessarily one GLB**. `Spec=ALIGNED` means the functional brief is domain-aligned; it does not mean production is complete.

## Acceptance rule

A family is not production `APPROVED` merely because one visual variant exists. Applicable requirements include:

- required property/capability distinctions remain semantically correct;
- transformation descendants and detachable components remain independently usable where specified;
- required interaction regions/adapters are supplied without becoming domain identity;
- mandatory regression contrasts remain readable from gameplay camera;
- reusable components remain interchangeable through semantic predicates rather than exact object recipes;
- production status and functional `Spec` are both updated accurately.
